# 检查项清单（Checkup Registry）v0.1

> 状态：**初版规格**。本文定义"系统能诊断什么"，是 PRD 与 AI 能力评估的共同底座。
> 约定：每条检查项都是**确定性计算**；LLM/VLM 只能选择检查项、不能发明检查项与参数。
> 修改日志见文末。

---

## 0. 设计约束

1. **单一职责**：一条检查项只回答一个可量化的问题。
2. **可测量**：输出必须是数值或有限枚举，不能是"看起来还行"。
3. **可复算**：同输入同版本 → 同输出。输入上附带版本与哈希。
4. **声明适用性**：不满足前置条件时返回 `not_applicable`，**不得硬算**。
5. **可行动**：每个 `problem` 级结论必须映射到白名单动作，且动作可由 `simulate` 预估收益。
6. **有代价**：任何建议必须能算出 Δ色数、Δ豆数、Δ分钟、Δ金额。

## 1. 统一数据结构

```json
{
  "check_id": "C05",
  "version": "1.0",
  "region": { "type": "whole | mask | bbox", "id": "r7" },
  "applicable": true,
  "metrics": { "p50": 3.1, "p95": 8.4, "max": 14.2 },
  "severity": 0.72,
  "level": "info | attention | problem",
  "evidence": { "tool": "region_delta_e", "input_hash": "sha256:..." },
  "actions": ["A01", "A05"]
}
```

**严重度分档**（统一口径）：

| level | severity | 是否呈现给用户 |
| --- | --- | --- |
| info | < 0.30 | 否 |
| attention | 0.30–0.60 | 仅高级视图 |
| problem | ≥ 0.60 | 是，最多 3 条 |

**严重度不是原始指标**，而是 `标准化后的指标 × 区域重要性权重`。区域重要性来自 P3 的显著性/主体/五官掩码。

## 2. 检查项总表

### 2.1 结构与几何（P1）

| ID | 名称 | 计算 | 输出 | 前置条件 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| C01 | 结构保真度 | 源图与图纸的边缘图相似度（SSIM on edges）+ 主体掩码内轮廓覆盖率 | 0–1 分数、最差区域 | 有主体掩码 | **P0** |
| C02 | 孤立块统计 | 连通域分析，统计 1–2 格孤立块占比与空间分布 | 占比、热图 | 无 | **P0** |
| C03 | 连通断裂 | 主体掩码内区域连通性；源连通 vs 图纸连通 | 断裂处列表 | 有主体掩码 | P1 |
| C04 | 缩略图可读性 | 按实际观看尺寸缩小后计算轮廓可辨度（梯度能量 / 剪影完整度） | 0–1 分数 | 已知成品尺寸 | P1 |
| C17 | 跨板风险 | 接缝线两侧 2 格内的高细节格数量、跨缝连通区域 | 风险格列表 | 多板 | P1 |

### 2.2 色彩（P2）

| ID | 名称 | 计算 | 输出 | 前置条件 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| C05 | 区域色差分布 | 逐格 ΔE00（源 patch vs 豆色），按区域聚合 | P50/P95/max + 热图 | 无 | **P0** |
| C06 | 色板缺口 | 区域内源色到最近豆色的 ΔE、缺失色相/明度区间 | 缺口列表、严重度 | 无 | **P0** |
| C07 | 色阶断裂 | 检测平滑渐变被量化成硬边：相邻格 ΔE 跳变 + 原图梯度 | 断裂位置、跨度 | 原图存在平滑渐变 | P1 |
| C08 | 色板浪费 | 每色使用格数；使用率低于阈值的颜色 | 浪费色列表 | 无 | **P0** |
| C09 | 肤色偏移 | 面部掩码内平均色相/彩度偏移（实测，非模型判断） | 偏移量、方向 | 有人脸掩码 | P1 |
| C10 | 邻色对比不足 | 相邻但不连通的区域对，其 ΔE00 低于辨识阈值 | 冲突区域对 | 有区域分割 | P1 |
| C11 | 全局色偏 | 源图与图纸在 LAB 上的均值/方差偏移 | 偏移向量 | 无 | P2 |

### 2.3 语义（P3）

| ID | 名称 | 计算 | 输出 | 前置条件 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| C12 | 关键特征清单核对 | 先从源图抽取特征清单（主体、五官、文字、标志物），再在图纸上逐条核对 | 逐条 present/partial/lost | 需要 VLM | P1（首个 AI 面） |
| C13 | 背景占比与干扰 | 背景掩码面积比 + 背景高显著性区域面积比 | 比例、建议 | 有主体掩码 | **P0** |
| C14 | 文字可实现性 | OCR 得字符数与字号；按网格算单字可分配格数 | 每字可分配格数、结论 | 检测到文字 | P1 |
| C15 | 构图完整度 | 主体 bbox 到画布边缘的余量、主体占比 | 余量、主体占比 | 有主体掩码 | P2 |

### 2.4 成本与交付（P5）

| ID | 名称 | 计算 | 输出 | 前置条件 | 优先级 |
| --- | --- | --- | --- | --- | --- |
| C16 | 用量与成本 | 每色格数 → 豆数（含 10% 损耗）→ 袋数 → 金额；预估工时 | 清单 + 总价 + 工时 | 已知售价 | **P0** |

## 3. 动作白名单（Action Registry）

LLM 只能从这里选择；参数有范围约束，超出即拒绝。

| ID | 动作 | 参数 | 影响 | 可逆 |
| --- | --- | --- | --- | --- |
| A01 | `raise_detail` | region, factor∈[1.5,3] | 局部提高采样权重；可能增加板数 | ✅ |
| A02 | `lower_color_count` | n∈[4,30] | 全局减色 | ✅ |
| A03 | `add_outline` | region, color_id, thickness=1 | 沿轮廓加一圈豆 | ✅ |
| A04 | `remove_islands` | min_area∈[1,3] | 清孤立块 | ✅ |
| A05 | `recolor_region` | region, palette_entry | 区域换色 | ✅ |
| A06 | `switch_palette_subset` | subset_id | 换子集策略 | ✅ |
| A07 | `enable_zone_dither` | region, strength∈[0,1] | 仅在指定区域启用图案过渡 | ✅ |
| A08 | `recrop` | bbox, mode∈{pad,crop} | 重裁 | ✅ |
| A09 | `pre_adjust` | brightness/contrast/saturation ∈[-1,1] | 源图预处理（反补偿） | ✅ |
| A10 | `replace_background` | mode∈{white,transparent,keep} | 背景处理 | ✅ |
| A11 | `enlarge_grid` | cells | 加板 | ✅ |
| A12 | `replace_text` | strategy∈{icon,enlarge,english} | 文字降级方案 | ✅ |
| A13 | `reseam` | axis, mode∈{offset,stagger} | 接缝重排 | ✅ |
| A14 | `force_symmetry` | axis∈{x,y} | 强制对称 | ✅ |

**所有动作必须实现 `simulate(action, params) → 指标变化 + 代价变化`**，否则不得进入白名单。

## 4. 触发规则（固定 workflow）

```
默认执行：C01, C02, C05, C08, C13, C16
条件执行：
  检测到人脸      → C09
  检测到文字      → C14
  检测到平滑渐变  → C07
  多板            → C17
  区域分割成功    → C03, C10
  用户主动诊断    → C12, C04, C11, C15
```

**上限**：每次最多呈现 3 条 `problem`，排序键为 `severity × 可修性 × (1/代价)`。

---

## 5. 检查项与 AI 的分工

| 检查项 | 数值来源 | AI 的作用 |
| --- | --- | --- |
| C01–C11, C13, C15–C17 | 确定性算法 | 仅解释措辞 |
| C12 | VLM 逐条核对（判断题） | 提供 present/partial/lost |
| C04 | 确定性分数 | 可选：VLM 判断"像不像" |
| 选择哪几条 | 规则引擎 | 可选：LLM 在菜单内重排 |

**边界**：AI 从不产出数值；任何 AI 结论必须绑定到某条检查项的 `evidence`。
