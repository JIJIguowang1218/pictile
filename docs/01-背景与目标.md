# 背景与目标

## 1. 拼豆是什么

拼豆（perler beads / fuse beads / Hama beads / 熨豆）是一种把塑料小豆按格子摆在带钉的
透明拼板上，拼好后用熨斗加热熔合的 DIY 手工。成品是像素画质感的实体物件：钥匙扣、
杯垫、立牌、相框画等。

手工领域的几个硬约束：

- **网格化**：图案必须落在正交网格上，一颗豆 = 一个像素。常见拼板为 29×29，也有 14×14、
  50×50 等规格，大图需要多块板拼接。
- **固定色板**：每个品牌有自己的一套颜色（几十到两百多色），规格常见 2.6mm / 5mm。
  用户手里通常只有其中一部分颜色，或者只愿意买有限几包。
- **颜色是离散的**：不能有渐变、抗锯齿、半透明。相近的两种颜色在豆子里可能就是同一颗。
- **物理尺寸**：板面越大，需要的豆子数量呈平方增长，时间和成本随之暴涨。
- **看得懂才拼得下去**：图纸需要清晰的分区、色号标注和用量统计，否则拼到一半会放弃。

## 2. 用户痛点

现有工具（在线像素化网站、修图软件手动减色、卖家提供的成品图纸）的问题：

| 痛点 | 表现 |
| --- | --- |
| 缩放即毁图 | 直接缩小照片会丢细节，脸糊、轮廓断裂、背景噪点满屏 |
| 不懂色板 | 输出 RGB 任意色，用户手上的豆子配不齐，或需要买几十种颜色 |
| 不会取舍 | 该强调的眼睛、轮廓被平均掉；该丢的背景杂物全留着 |
| 不估算成本 | 不知道总共要多少颗、分几种颜色、要几块板、大概多少钱 |
| 图纸不可用 | 只有一张像素图，没有网格线、色号、图纸分页，打印出来没法照着拼 |
| 不会拼多板 | 大图不知道如何切分到多块拼板，接缝处容易错位 |

## 3. 产品目标

**一句话**：让没有美术和软件基础的人，在几分钟内得到一张"买得到豆子、拼得完、拼出来好看"的图纸。

具体目标：

1. **输入宽容**：照片、插画、文字描述（AI 生成底图）都能作为起点。
2. **语义感知的简化**：不是机械缩放，而是识别主体与关键特征（脸、眼、轮廓、文字），
   优先保留这些信息；背景与次要细节主动舍弃。
3. **受约束调色**：只在用户可获得的色板内选色（指定品牌，或用户自有的颜色清单），
   可限制总色数（例如"最多 8 色"），并给出近似色替代建议。
4. **可执行的交付物**：网格图纸（含色号/符号）、分板切分与接缝标记、颜色用量清单、
   预估成本，导出为可打印 PDF 或高分辨率 PNG。
5. **所见即所得**：预览尽量接近真实拼豆成品的观感（豆子颗粒、间隙、熨烫后的饱满度）。

## 4. 典型场景

- **个人玩家**：把宠物照片 / 爱豆照片 / 游戏角色做成 29×29 的小挂件。
- **送礼物的人**：做一张 4 板拼合的人像或风景，需要图纸足够清晰、配色靠谱。
- **小店 / 摊主**：批量出图接单，关心出图速度、材料成本、图纸专业度。
- **亲子 / 教学**：小孩能看懂的图纸，色数要少、区域要大、不要碎点。

## 5. 非目标（当前阶段）

- 不做拼豆的电商与库存管理（但会考虑"按我的库存出图"）。
- 不做 3D 建模、立体拼豆结构设计。
- 不做社区/作品分享平台。
- 不追求照片级还原——拼豆的媒介本身决定了它是高度抽象的，目标是"神似且拼得完"。

## 6. 成功标准（初稿）

- 一张普通照片，在 29×29、≤12 色的条件下，主体可辨认、无明显噪点、轮廓完整。
- 生成的用量清单与真实取豆误差在可接受范围（无浪费性错误）。
- 从导入到拿到可打印图纸，非专业用户 5 分钟内完成。
