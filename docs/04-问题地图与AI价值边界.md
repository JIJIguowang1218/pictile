# 问题地图与 AI 价值边界

> 状态：**开放性梳理稿**，条款不固化。
> 本文只做分类、边界判断和原则，不进入具体实现。
> 前置：[`03-头脑风暴-AI介入与技术栈.md`](03-头脑风暴-AI介入与技术栈.md) 讨论的是"怎么做"，本文讨论"到底在解决什么问题、AI 能替人承担到什么程度"。

---

## 1. 问题地图：拼豆到底在解决哪些问题

把整件事按"需要什么知识"切开，而不是按流水线顺序切。因为按流水线切，会看不出哪一层的困难本质不同。

| 层 | 要解决的问题 | 需要的知识 | 谁来判断 |
| --- | --- | --- | --- |
| **P0 材料物理** | 豆/板规格、接缝、熨烫形变与色变、实际观感、色板离散且跨品牌不等价 | 材料 + 制造 | 实测 |
| **P1 栅格几何** | 采样与混叠、分辨率预算、连通性、孤立点、细线断裂、多板切分 | 图像处理 + 像素画技法 | 确定性算法 |
| **P2 色彩** | 色差度量、色域映射、有限色板量化、色阶设计、白平衡、同时对比、记忆色 | 色彩科学 + **审美** | 算法 + 语义先验 |
| **P3 语义** | 主体与背景、显著性、五官、文字、构图 | 计算机视觉 | 感知模型 + VLM |
| **P4 认知交互** | 用户不会描述、参数耦合、不知道自己想要什么、判断不了好坏 | 人机交互 + 认知心理 | 产品设计 |
| **P5 经济流程** | 成本、时间、库存、拼装顺序 | 运筹 | 计算 |

### 三个结构性观察

**观察一：P2 是最被低估的一层，因为它一半可算、一半不可算。**
色差可算（CIEDE2000），但"这组颜色搭起来脏不脏""这张脸是不是偏黄了"不可算。专业调色的能力恰恰长在不可算的那一半上。任何只做 P2 可算部分的系统，都能出"正确但难看"的图。

**观察二：各层不独立，任何单层最优都可能让整体变差。**
P2 的选色依赖 P3 的判断（什么重要）、P4 的意图（用户要什么），并受 P0 的约束（买得到什么）；P1 的粒度又限制了 P2 能操作的空间。所以"把每一层都调到最优"这条路走不通，必须整体决策或分层带反馈。

**观察三：P4 不是"界面问题"，它是这个产品能不能成立的前提。**
用户看不懂的正确答案等于错误答案。而 P4 的解法不能是"多给几个滑杆"——那只是把专业难度转嫁给用户。

## 2. 专业问题怎么变成用户能理解的东西

### 2.1 先承认一个事实：专业调色师的工作流本来就是为"客户说不清"设计的

真实调色流程是：客户说不清 → 调色师给两版 → 客户选 → 微调 → 定稿。
**我们该复制的是他的工作流，不是他的参数。** 参数面板是把"调色师的脑子"直接摆到用户面前，方向就错了。

这个工作流里，调色师替客户承担了三件事：

| 调色师承担的东西 | 系统里谁来承担 |
| --- | --- |
| **词汇**——把"怪怪的"翻译成具体的调整 | LLM（语言层） |
| **品味**——知道什么好看 | VLM 裁判 + 用户偏好数据 |
| **迭代**——快速试、低成本改 | 确定性重算 + 候选预计算 |

三者都能被替代。这就是"AI 介入"在这个产品里真正的立足点：**不是让算法更聪明，是替用户承担他的三个缺口。**

### 2.2 控制范式：从"调参数"改成"诊断—处方—验收"

```
默认出图（0 次决策）
   │
   ├─ 系统体检（确定性指标）── 无问题 → 结束。多数用户到此为止。
   │
   └─ 有问题 → 最多 3 条诊断（按 严重度 × 可修性 × 代价 排序）
                    │
                    ├─ 每条附 1 个一键修复
                    ├─ 每条附 2 个替代方案
                    └─ 每条附"代价"：多几色 / 多几十分钟 / 多几块钱
                              │
                              └─ 用户点一下 → 前后对比 → 接受或换
```

### 2.3 五条原则

1. **给后果，不给属性。** 用户不调"亮度/对比度/彩度"，用户选"更清楚 / 更省豆 / 更像原图"。
2. **建议必须带代价。** "加 2 色脸会清楚，但要多买 1 包豆、多拼 15 分钟"——带代价的建议用户能判断，不带代价的建议用户无从决策。**代价本身就是解释。**
3. **限制选项数量。** 每次最多 3 条诊断、每条最多 3 个选项。选项多了不是更自由，是更焦虑。
4. **默认必须是 0 决策。** 绝大多数图不该出现任何可调项。出现 = 系统失职。
5. **凡事可解释一句。** 任何自动决定都要能回答"为什么"（"背景被压成 2 色，因为你要 29×29"）。可解释 ≠ 可调。

### 2.4 一条可操作的验收线

**用户每张图最多做 1 次决策，每次不超过 3 个选项。** 超过就说明系统承担得不够，而不是用户不努力。

## 3. VLM 能不能做"原图 vs 图纸"的对比分析

结论先给：**能做语义层，不能做数值层；而且它的正确用法不是"看两张图找不同"。**

### 3.1 能力边界（诚实版）

| 任务 | 能力 | 结论 |
| --- | --- | --- |
| 还能认出主体吗 | 强 | ✅ 可用 |
| 关键特征（眼/嘴/文字/轮廓）还在不在 | 中强 | ✅ 可用，但要给特征清单 |
| 指出哪个区域失真 | 弱（只能粗定位，框级别） | ⚠️ 需接地 |
| 失真有多严重（ΔE / 像素数） | 无 | ❌ 绝不用 |
| 数豆子、数颜色 | 无 | ❌ 绝不用 |
| 不规则区域的"对应关系" | 弱 | ⚠️ 用已知对应替代 |
| 两个方案哪个更好 | 较强 | ✅ **首选用法** |
| 色彩是否"脏/和谐/偏" | 中 | ✅ 可用，作为审美判断而非精度 |
| 记忆色（肤色该暖、天空该蓝） | 中强 | ✅ 可用，且是 ΔE 做不到的 |
| 多次调用结果一致 | 弱 | ⚠️ 需选票 + 结构化评分 |

### 3.2 关键澄清：不规则区域不需要模型去找对应关系

**因为转换是我们自己做的，任意区域在原图和图纸之间的对应关系是已知的。**

- 源图上的任意掩码（用户圈的、分割出的、模型指的）可以直接传播到图纸上，逐格算出该区域的 ΔE 分布、色数、连通性、边缘保真。
- 图纸上的任意区域也可以反查回源图对应的 patch，回答"你这 12 颗豆原本是什么"。
- 用户圈一块不规则区域问"这里为什么脏"，可以精确回答："这块原图是渐变，色板里没有中间色，只能用两种豆交错，所以看着碎。"

**所以不规则区域的保真度是确定性计算的，不需要 VLM。** VLM 只负责回答两件算法答不出的问题：**这个区域在语义上是什么、它的失真用户能不能接受。**

### 3.3 正确的架构：确定性体检 + VLM 读片

```
源图 ──[确定性流水线]──► 图纸
                          │
                          ├─ 逐格 ΔE 热图
                          ├─ 区域保真表（任意掩码可查）
                          ├─ 结构/孤立点/连通性
                          └─ 色板覆盖与浪费
                          │
                    ┌─────┴──────┐
                    ▼            ▼
            [确定性体检报告]   [VLM 语义解释]
              （数值权威）      （语义权威）
                    └─────┬──────┘
                          ▼
                    [白名单动作] → 确定性重算 → 实测改进量
                          │
                    改进量达标？ ── 否 → 驳回，回灌
                          │是
                          ▼
                      呈现给用户
```

VLM 的输入不是"两张原始图"，而是**两张图 + 数值报告 + 特征清单 + 区域编号**。它不负责发现数值问题，只负责给数值问题赋予语义。

### 3.4 三个让它可靠起来的技巧

1. **特征清单代替开放式评价。**
   不要问"评价一下这张图"。先列出原图的可拼特征（主体、五官、轮廓、文字、主要色块），逐条问"图纸里还在吗"。判断题比开放题稳定一个数量级。

2. **成对比较代替绝对打分。**
   "A 和 B 哪个更像原图"远比"这张打几分"可靠。所以产品里永远给候选让用户选，而不是给分数让用户信。

3. **区域编号接地。**
   把分割区域的 ID 叠在图上给 VLM 看，它说"region 7 的边界塌了"，就能精确映射回掩码。让模型做相对指代，不让它做像素定位。

### 3.5 VLM 在色彩上唯一的合法贡献：记忆色

ΔE 是纯数值的，它不知道"这是东亚人的脸，不该变成橙色"。VLM 有世界知识：肤色该暖、天空该蓝、草地该绿。这层先验能把"数值正确但观感错误"的结果救回来。

**这是 AI 进入 P2 色彩层唯一站得住的理由，而且它属于语义先验，不属于色彩计算。** 分工不能混。

### 3.6 必须承认的三个风险

- **视觉编码器会降采样。** 1–2 像素级的错误在它的patch网格下就是噪声。所以它只能判"区域级"，不能判"格子级"。格子级永远是确定性指标的活。
- **它会自信地胡说。** 所以必须有白名单动作 + 实测改进量驳回机制。
- **它不稳定。** 所以关键判断要多次采样投票，而且要监控"模型判断与用户接受率的相关性"。**如果这个相关性不成立，整个"AI 辅助"的故事就不成立。**

## 4. AI 该介入的全景（按层）

| 层 | AI 该做的 | AI 不该做的 |
| --- | --- | --- |
| P0 材料 | 无（读库存已搁置） | — |
| P1 几何 | 无。几何上模型没有任何优势 | 采样、切分、清理 |
| P2 色彩 | 记忆色先验、审美和谐、色彩"脏/偏"的语义判断 | 色差、色数、选色号、计数 |
| P3 语义 | 主体、显著性、五官、OCR、图像类型分类 | — |
| P4 交互 | 意图翻译、诊断解释、**决定问什么**、偏好学习 | 让用户做超过 3 个决策 |
| P5 经济 | 无（纯计算） | — |

### 四个还没被提到、但我认为价值很高的介入点

1. **AI 当提问者。**
   不是"多问几个问题"，而是**只在答案会改变结果时问，并按"能减少多少不确定性"排序**。多数图不该被问任何问题；模糊的图只问 1 个问题。会提问和会闭嘴同等重要。

2. **AI 当谈判者。**
   把"做不到"变成"这样做可以，代价是……"，并且**给 2–3 个替代方案而不是一句拒绝**。用户要的不是判决，是选项。

3. **AI 当输入侧的风格翻译器。**
   把照片转成"适合拼豆的底图"（扁平、粗轮廓、低高频、限定色相）。这是全链路杠杆最高的一环：输入端改善 1 分，输出端能放大成 5 分。

4. **AI 当 A/B 解释器。**
   对比两个候选变体，用人话说明差异。风险最低、感知最强、实现最简单。适合作为"AI 能力"的第一个上线点。

### 5. 重新定义 AI 的价值标准

不要用"AI 让图更准"来衡量。用这个：

> **每张图纸上，用户需要做的决策数量。**

目标是 0–1。每一个 AI 功能都应该回答："它替用户吸收了几个决策？" 如果答案是 0，这个功能就不该做——哪怕它很酷。

这条标准同时解释了为什么不能有那么多调节按钮：**按钮 = 决策 = 系统没承担。**

## 6. 待验证的三个假设（按风险排序）

1. **VLM 的相对判断与人的偏好是否一致？**（最高风险，决定"AI 辅助"是否成立）
2. **"诊断—处方—验收"是否真的能让用户 1 次决策内满意？**（决定 P4 方案是否成立）
3. **记忆色先验是否能稳定修正 ΔE 无法发现的美观问题？**（决定 AI 是否值得进 P2）

三个都成立 → 这是个 AI 产品。第 1 个不成立 → 这是个好用的工具，但别讲 AI 故事。
