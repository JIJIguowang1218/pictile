## 2. 已锁定的判断（不要再重复讨论）

| # | 判断 | 依据 |
| --- | --- | --- |
| 1 | **转换过程不用生成模型**：采样、量化、清理、排版全部确定性算法 | 可预测、可局部修正、可解释；生成模型三项皆失 |
| 2 | **AI 只做感知、诊断、解释、意图**，不产数值、不改图、不默认介入 | `04`、`10` |
| 3 | **VLM 不是裁判，是解说员 + 候选排序器 + 指代解析器** | ColorBench 55.4% vs 人类 92%；成对 0.636–0.773 vs 打分 0.490 |
| 4 | **产品目标是"收敛"，不是"可复现"**：生成可随机，应用必须确定 | `07` |
| 5 | **用户每张图最多 1 次决策**；默认路径 0 决策 | `04`、`09` |
| 6 | **差异化不在功能，在判断力**：分区精度、诊断、解释、成本、可行性 | 竞品功能已饱和，见 `06` |
| 7 | **国内主流品牌是 MARD**（221 标准 + 70 扩展 = 291），不是 Artkal | 竞品页面实测 |
| 8 | **公开 HEX 只是近似**，必须预留实测 LAB 与色板版本 | `05` §7.2 |
| 9 | **规则引擎必须能决定"什么时候不用 AI"** | `10` §5.1 |

## 8. 术语速查

| 术语 | 含义 |
| --- | --- |
| 检查项（checkup） | 一个确定性诊断计算，输出数值 + 区域 + 严重度 |
| 动作（action） | 白名单里的一个可执行变更，必须支持 simulate |
| simulate | 应用某动作后，预测各项指标与代价的变化 |
| 配方（recipe） | 参数集 + 色板版本 + 工具输出快照，用于撤销/分享/批量 |
| 决策数 | 用户从上传到导出之间做出的选择次数，北极星指标 |
| 区域 ID | 分割/用户圈选产生的掩码标识，是 AI 与工具的共同语言 |
