# 色板数据

## MARD 221 / 291

- 文件：`mard221.csv`（A–H + M 系列）、`mard291.csv`（全色）。
- 来源：[beadsheet.com](https://beadsheet.com/) 的 `palettes.js`；其注释标明 MARD 数据来自 [makebead/craft-color-codes](https://github.com/makebead/craft-color-codes) 的 `data/csv/mard-291.csv`，许可 **CC BY 4.0**。
- 性质：社区整理、屏幕近似值，**不是分光仪实测 LAB**。批次、光线、屏幕差异都会影响观感。
- 用途：v1 的近似色板；落地前必须用实测色值覆盖，并保留版本与来源。
- 抓取脚本：`scripts/fetch_mard_palette.py`。
