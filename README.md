# pictile

> **picture + tile** —— 把一张图片，变成可以照着拼的拼豆图纸。

## 这是什么

pictile 是一个 AI 辅助的拼豆（perler / fuse beads）图纸生成工具。用户给一张图片或一段描述，
pictile 输出一张**能直接照着拼**的像素图纸：网格、色号、每色豆子用量、拼板拼接方式，以及可打印的文件。

它不是简单的"图片缩小 + 像素化"：普通缩放会把画面糊成一团噪点，而拼豆的物理限制（固定色板、
有限板面、买家只想买得起的分量）需要专门的算法与判断。

## 命名

`picture` + `tile`，取"把画面切成一颗颗豆子"之意。中文可叫「拼图豆」。
